MarigoldOS v0.8.0 for Xteink X4 and X3.

### What's new
- Faster page turns on the X4 (300 ms instead of 421 when the panel is warm).
- The next page is prepared while you read, so turns start almost as soon as you press.
- Button presses register sooner on the X4.
- Better justified text: fewer ragged lines and fewer hyphens stacked down the margin, most noticeably in portrait.
- Smaller firmware: the built-in fonts take half the space and draw faster, with no change to how text looks.

### Updating
| Device | Image | Automatic SD update filename |
| --- | --- | --- |
| X4 | `firmware-x4.bin` | `FWUPDATE.BIN` |
| X3 | `firmware-x3.bin` | `FWUPDX3.BIN` |

Rename the image as shown, put it in the SD-card root, and reboot, or use Settings → Firmware update. For the stock updater, rename it to `update.bin` and follow the [installation instructions](https://github.com/Jon-Vii/marigold-os/blob/v0.8.0/docs/FLASHING.md). USB flashing uses offset `0x10000`.

Each book rebuilds its cache the first time you open it, because lines now break differently. Saved positions are kept.

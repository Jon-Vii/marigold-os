MarigoldOS v0.5.0 improves reader responsiveness and cache recovery on Xteink X4 and X3.

### Reader improvements
- Open only enough of an EPUB to reach the requested page, instead of building the entire book first. Completed cache prefixes survive interruption and resume when needed.
- Reflow completed caches after line-spacing changes without parsing the EPUB again.
- Avoid duplicate refreshes on RAM-cached page turns and preserve the actual reading position when a chapter jump is cancelled.
- Stop missing-file lookups at FAT's end-of-directory marker. The final X4 validation loaded a 35-book catalog in 146 ms.
- Reuse custom-font glyph bitmaps within each page and update only the trailing page during incremental pagination.
- Use full-sector DMA transfers on X4. Experimental contiguous SD reads remain disabled by default.

### Validation and limits
X4 hardware passed 50 alternating page turns, five consecutive sleep/wake cycles, cold opening, spacing reflow, cancellation, and SD-backed glyph pixel checks. X3 release builds and host tests passed; X3 hardware was not available for this release's validation. Cache builds yield between source spines, so a very large chapter can still delay cancellation. Complete-cache spacing reflow is synchronous.

### Updating
Download the image matching your device:

| Device | Image | Automatic Marigold SD update filename |
| --- | --- | --- |
| X4 | `firmware-x4.bin` | `FWUPDATE.BIN` |
| X3 | `firmware-x3.bin` | `FWUPDX3.BIN` |

For Marigold's automatic SD update, rename the selected image as shown, place it in the SD-card root, and reboot normally. Alternatively, use Settings → Firmware update with the canonical `.bin` filename.

For the stock/OEM SD updater, rename the correct device image to `update.bin` and follow the [installation instructions](https://github.com/Jon-Vii/marigold-os/blob/v0.5.0/docs/FLASHING.md). The website supplies the appropriate download filename automatically.

These are app-only images. USB flashing uses offset `0x10000` and preserves the bootloader and partition table. This release publishes one image per device plus `SHA256SUMS`; updater-name aliases are no longer separate assets. Existing book caches may rebuild after the layout changes; saved reading positions are retained.
